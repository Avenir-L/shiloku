# 2026-11-17 安全加固

## 已实施
- Vercel 正式项目 avenir：API 同 IP 180 次/60 秒入口限流，已发布，规则 ID rule_api_read_flood_protection_MwkyuU。可在 Firewall 禁用此规则回退。
- 应用层按实例增加数据库前限流（默认 IP 60、实例总计 600 次/分钟）；拒绝请求不访问 Redis。状态写入为 IP 30、实例 300 次/分钟。
- 合并同时到达的相同说说/评论/主站内容/留言查询；不缓存说说结果，避免隐藏后仍公开。保留状态 30 秒 CDN 缓存及图片不可变缓存。
- 留言发布保留单 IP 5 次/分钟，新增全站 100 次/分钟预算。后台可按已有留言 ID 删除，无历史数据自动裁剪。
- 状态同步密钥改为 SHA-256 等长摘要的 timingSafeEqual；取消写接口通配 CORS，保留服务器端脚本调用。
- 公开说说/主站内容不返回编辑 revision；听歌统计保留原有展示数据，去掉账号 ID 与昵称。
- cdn.shiloku.cn 临时重定向到 www.shiloku.cn，避免同一站点来源不匹配。
- 头像使用正式域名；状态读取不再自动访问可变 GitHub/CDN 回退源，保留已部署本地状态回退。

## 边界
- 内存限流和请求合并仅在同一个函数实例内有效；多实例入口主要由 Vercel 防火墙处理。不能承诺抵挡特定规模的 CC/DDoS。
- 单 IP 规则不能完全防住分布式或慢速耗额攻击，也不是数据库每日额度的硬预算；共享 Redis 仍是后台依赖。需结合实际账单和用量告警评估独立存储/配额升级。
- 未新增人机验证码（需要配置及交互评估），Origin 不作为脚本认证。
- 未修改 SPF/DMARC/CAA：应先核实实际邮件用途及证书签发机构。未修改或轮换现有有效密钥。
- 仅做本地模拟防刷测试与少量线上功能验收，不进行线上压测，不发布或删除真实内容。
