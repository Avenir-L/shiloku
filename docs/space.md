# 日常发布

登录后台，进入「我的空间」，点击「写说说」。填写正文、添加最多 9 张图片，或粘贴最多 6 个平台分享链接，选择「存草稿」或「发布说说」。列表提供编辑、置顶、删除；已发布内容可转回草稿。

主站第三页「进入日常」指向 `/space/`，详情使用 `/space/?id=<id>`。头像与昵称读取主站内容设置。公开页面不包含示例说说。

草稿只有站长接口可读，公开详情同样拒绝读取草稿。所有写入沿用后台身份校验、同源保护及限流。修订号通过 Redis Lua 原子比较，旧编辑页不能覆盖新版本，删除保留内部墓碑避免旧页面重建内容。

Redis 数据键为 `shiloku:space:v1:post:<id>`，管理列表和公开列表分别使用 `shiloku:space:v1:all`、`shiloku:space:v1:public` 排序索引。公开列表置顶优先，随后按发布时间倒序。编辑已发布内容保留发布时间。

图片使用已有 `/api/site-content` 上传与不可变图片接口，保存说说时保留引用图片。平台链接只接受允许的 HTTPS 域名，逐跳校验重定向并限制抓取时间、大小；标题与封面读取失败时仍显示可点击链接，不承诺平台允许内嵌播放。

`node scripts/admin-preview.mjs` 提供完全隔离的内存预览，不连接生产 Redis。`npm run test:security` 包含发布权限、草稿隔离、修订冲突、删除、排序与链接安全测试。
