# Cursor and Layout Polish Design

The homepage returns to the operating system cursor by disabling both the decorative cursor ring and its particle trail. This removes the white blurred bloom that can overlap page text.

On page two, the footer cluster remains structurally anchored below the centered time content but is shifted lower within the available page space. On page one, the `个人简介` heading keeps character-level hover behavior while using an inline flex row so its letters stay compact and centered instead of inheriting justified text distribution.
